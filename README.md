# Driver Route Helper GitHub Pages Files

Upload these files to the root of your `Driver-Guide-Privacy` GitHub repository.

## Files

- `index.html` — main landing page
- `privacy.html` — matching privacy policy page

## URL behavior

After uploading:

- Landing page: `https://aimedtoannoy.github.io/Driver-Guide-Privacy/`
- Privacy policy: `https://aimedtoannoy.github.io/Driver-Guide-Privacy/privacy.html`

## Important

Your current live page is the privacy policy at the root URL. Replacing the root `index.html` with the new landing page will move the privacy policy to `privacy.html`.

If your app store listing already points directly to:
`https://aimedtoannoy.github.io/Driver-Guide-Privacy/`

and it must remain a privacy-only page, then do not replace the current root page. Instead, create a separate repo for the landing page.
